## Sobre o projeto

O Brasil é um dos maiores produtores de mel do mundo, mas a maioria dos apicultores — especialmente os pequenos e familiares — ainda enfrenta dificuldades para acessar mercados consumidores dispostos a pagar pelo valor real do produto.

A **Rede Colmeia Brasil** conecta diretamente produtores de mel a consumidores e estabelecimentos do mercado gourmet, valorizando a produção artesanal e fortalecendo a cadeia apícola brasileira.

A plataforma permite:

- Cadastro e perfil de produtores com portfólio de produtos
- Exibição de produtos gourmet com informações de origem
- Divulgação de eventos e formações técnicas na área de apicultura
- Painel administrativo para gestão de cadastros e publicações

## Como configurar

```bash
# 1. Clone o repositório
git clone https://github.com/jayne-medeiros/rede-colmeia-brasil.git

# 2. Crie um banco de dados MySQL

# 3. Renomeie o arquivo de configuração
mv admin/config.php.template admin/config.php

# 4. Preencha as credenciais do banco de dados e as configurações
#    de administrador no arquivo admin/config.php

# 5. Certifique-se de que a pasta uploads/ tenha permissão de escrita
#    para o servidor web
```

## Contexto

Projeto desenvolvido como parte das iniciativas de **inovação social e digital para cadeias produtivas rurais** da [Lumio Lab](https://hlumio.com/portfolio), com foco em criar mercados mais justos e acessíveis para produtores do campo brasileiro.

A apicultura tem papel importante na biodiversidade e na geração de renda em regiões do semiárido, Cerrado e Amazônia — e este projeto nasce do reconhecimento desse valor.
